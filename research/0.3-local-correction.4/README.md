## 3. correction.4 추가 설계 후보

### A. 개인·자료·질문 단위와 항목별 격리

`case_id / track_id / subject_id / material_id / question_id`를 분리한다. 같은 사건번호의 여러 사람과 같은 검체의 다른 부분을 섞지 않는다. 잘못된 출처는 해당 관찰과 실제 의존 결론만 보류하고 관련 없는 정상 근거의 경고를 지우지 않는다.

동일 자료를 항소나 관련 절차에서 사용할 때는 원자료 식별자를 유지하되 절차별 사용·허용 관계를 명시적으로 기록한다. 같은 질문을 반복 입증시키는 새 제출 의무를 만들지 않는다. 기존 scanner가 미등록 `*_ref`를 보류하므로, 새 참조 필드와 의존 관계는 스키마·검증기·시험에 함께 등록해야 한다.

### B. 발화자·행위·결정·귀속 연결

`event_id / actor_id / actor_role / statement_role / event_type / occurred_at / source_ref`를 검토한다. 피고의 요구, 원고 진술, 법원의 결정, 참관인의 해석은 별도 종류다. 법원이 거부했다고 판단하려면 입력된 REFUSED 라벨만이 아니라 그 귀속 근거와 반대 자료를 함께 검사한다.

이름이 미확정이면 일반 검증 제한 경고와 식별 과제를 보존하되 특정인에 대한 귀속은 보류한다. 유족 진술도 출처로 연결할 수 있으며 공식 기관 문서만 경고의 유일한 진입 조건으로 만들지 않는다. 문자열 일치는 의미·진실·진위 인증이 아니다.

### C. 제출한 자료와 실제 판단의 반영 여부 대조

연구자료, 생전 증상, 과거 반응, 유족 진술을 질문별로 다음 차원에서 구분한다.

- 제출·진술의 근거와 접수·법정 발언 상태
- 판단 문서의 언급 여부
- 실질 검토와 배척 이유의 확인 상태
- 판단자료 미확보 때문에 확인하지 못한 부분
- 남은 설명 요구와 담당 지원 노드

판결문에서 표현을 찾지 못했다는 사정만으로 미검토를 확정하지 않는다. 반대로 서류가 접수됐다는 사실만으로 실질 심리가 끝났다고 처리하지 않는다. 진료기록 부재를 증상·진술·피해의 부재로 변환하지 않는다.

### D. 자료 구별 질문과 통제자 설명책임

연구용 후보물질과 개별 접종 LOT의 연결·구별을 묻는 경우, 연구자료 존재만으로 동일성을 확정하지 않고 BMR·CoA 부존재 회신만으로 구별 완료를 선언하지 않는다. 생성·보유·검색·이관·폐기 경위와 대체 구별 자료를 질문별로 추적한다.

EAS는 자료·사본·행위자·확인 시점별로 AVAILABLE / RESTRICTED / WITHHELD / NOT_SEARCHED / LOST / DESTROYED / UNKNOWN의 7개만 사용한다. UNKNOWN 또는 AI의 검색 실패를 기관의 부존재나 피해자의 거짓으로 바꾸지 않는다. 필요한 검색과 기존 자료 대조는 지원 노드의 일로 배정한다.

### E. 현재 심급에서 작동하는 사법적 설명책임·징계 검토 후보

검증 요청, 제한 결정과 이유, 대체 경로, 남은 증거 공백, 그 공백의 불리한 사용, 기관에 유지된 이익을 연결한다. 초기 경고나 조사 필요성 검토에 항소 완료·최종 패소·고의 또는 범죄의 선입증을 요구하지 않는다. 하나의 중대한 행위도 검토를 열 수 있으며, 반복은 후속 처리의 검토 요소이지 초기 경고를 미루는 조건이 아니다.

반복 패턴은 같은 문서의 사본 수나 재제출 횟수가 아니라 구별되는 행위·결정과 설명·시정 요구 이후의 처리로 검토한다. 구체적 행위·관련 의무·결정 이유·반대 자료·피해 영향을 연결해 **독립 조사 및 법관 직무상 책임·징계 사유 검토 경고**를 제안할 수 있도록 한다. 경고 조건·등급은 R3 검토 대상이며 이번 게시로 자동 적용하지 않는다.

`reason_status=NOT_OBTAINED`와 실제 이유 없음, 피고의 불채택 요구와 법원의 결정, 불리추정 검토 요청과 법원의 실제 인정은 구분한다. 관할 기관·적용 의무·소명·반박·정정 절차를 검토 자료에 포함한다. 이는 AI의 징계 결정·유죄 확정·외부 집행이 아니다.

### F. 시정 상태와 과거 부담을 함께 보존

검토 허용 결정과 전문가의 실제 열람·검경은 별개 사건이다. 질문별로 검증이 실제 가능해졌는지, 일부만 해소됐는지, 미해결인지 갱신한다. 의미 있는 시정이 확인되면 현재 경고 범위를 정정할 수 있어야 한다.

나중에 검증이 열렸다고 이전 제한·지연·비용·유족의 고통을 없애지 않는다. 반대로 부분 시정이 있었는데 계속 전면 차단이라고 표시하지 않는다. 기간과 비용의 근거·범위를 기록하고 미확인 금액은 null로 둔다. 고통을 임의 점수로 환산하거나 매번 새로 입증시키지 않는다.

## 4. 추가 수용 시험 후보

1. 피고 요청만 존재: 요청은 보존하되 법원 거부로 귀속하지 않음.
2. 외부 사건 항목 하나 혼입: 해당 항목·의존 결론만 보류, 정상 경고 유지.
3. 같은 사건번호의 다른 아이 자료: 개인·검체 범위 혼합 차단.
4. 이름만 바뀐 행위자: 특정 주체 경고의 귀속 보류, 일반 검증 질문 유지.
5. 같은 문서 중복 10개: 별도 행위 10건으로 세지 않음.
6. 1심에서 확인된 제한: 항소 결과 없이 현재 경고 검토 가능.
7. 후속 감정 허용만 있고 미열람: 검증 완료로 바꾸지 않음.
8. 일부 자료 실제 열람: 해당 질문만 갱신, 다른 미해결 질문 유지.
9. 시정 또는 잘못된 귀속 발견: 현재 표시 정정, 정정 근거와 과거 부담 보존.
10. 기관의 부존재 회신: 원자료 구별 완료·자동 면책으로 바꾸지 않음.
11. 반복 설명·새 서류 요구 없이 이미 연결된 유족 진술과 자료를 재사용.
12. 정당한 제한 사유와 실제 대체 검증 경로가 확인된 경우 반대 근거도 보존해 경고 범위를 재검토.

수용 시험의 통과는 실제 사건 인과성·법적 책임·사법부 위법의 인증과 구분한다. 출처·의미·법률 및 의학적 적용의 독립 검토는 별도다.
