## 우선 목적과 목적 함수

가장 먼저 만드는 결과물은 피해자 지원 서면이다. 증거표에서 출발하여 주장, 원자료 요청, 기관별 설명 요청, 필요한 전문 검토와 구제 신청 후보까지 연결한다. 최고 로펌 수준의 지원은 개발 목표이며 현재 달성·승소율 상승을 측정한 결과가 아니다.

목적은 다음 순서의 사전식 최적화로 제안한다. 가중치나 총점의 신규 승인은 아니다.

1. 사실·인용·통계의 오류와 근거 없는 법적·의학적 확정을 막는다.
2. 주장을 원자료와 연결하고 불리한 자료·전문가 이견·불확실성을 보존한다.
3. 증거 편재와 검증 공백을 통제자별 제출·설명·보존 요청으로 바꾼다.
4. 사건과 관할에 맞는 구제 요청의 완성도를 높인다.
5. 이미 받은 자료를 재사용하고 피해자의 반복 진술·비용·기관 내부 감사 부담을 줄인다.

제약: 공리 불변, 승인과 실행 권한 구별, 자동 유죄·자동 면책 금지, 방해로부터 이익 금지. 사실을 유리하게 왜곡해 승소를 최적화하는 목적 함수는 채택하지 않는다. 설명책임의 설계상 배정과 실제 재판의 법적 입증책임은 구별하고 후자는 적용 법령·판례 및 대리인 검토로 판단한다.

## 실제 구현 범위

| 모듈 | 현재 로컬 코드 | 남은 검증 |
|---|---|---|
| CC-VERIFY-01 | 제공된 사건번호·법원·선고일과 구조화된 인용 메타데이터, 직접 인용문 대조 | 법원 원문 직접 조회, 진위·최신 법리·사안 적용 검토 |
| CC-VERIFY-02 | 제공된 논문 제목·저자·연도·DOI, 대상·개입·결과·추적기간·연구설계·분모·분자·인과층 대조, 비율 산술 검사 | 논문 직접 조회, 원자료 통계·편향·의학적 타당성 평가 |
| CC-VERIFY-03 | 불필요한 양보 후보와 필요한 유보 문구 구별, 원문 보존, 증거 편재 경고 | 문맥·소송전략에 대한 대리인 확인, 표현 탐지의 누락·오탐 평가 |
| 지원 서면 생성 | 입력 증거표·질문·통제자·자료 목록·구제 요청 후보를 서면 초안으로 구성 | 실제 사건별 청구·쟁점·서증번호·적용 법령 연결, Word 제출본 편집 |
| CT-RULE-6.3/6.4 연결 | 검토 트리거, 통제자·담당 공백, 입력된 시계와 지연, 이송 후 원시점 보존 | 실제 기관 접수·법정 기산·공휴일표·기간 연장 원문 검증 |
| 기술 정합성 루프 | 제한된 횟수의 재실행·결과 해시 안정성·잠금 위반 검사·미해결 항목 보존 | 자동 보완 제안의 의미 검증, 0.2 중앙 코어 통합, 외부 독립 재현 |

검색 실패는 허위 판례 확정이 아니다. 제공 원문의 문자열 일치는 실제 판례·논문의 인증이나 그 해석의 정당성 인증이 아니다. 발췌문에서 인용을 찾지 못하면 UNVERIFIED로 남긴다. 제공자가 FULL_DOCUMENT로 표시한 전문에서 찾지 못한 경우도 제공 텍스트 기준 MISQUOTED이지 공식 원문 인증 완료가 아니다. 정확한 바이트 해시 일치도 문서 진실성을 보증하지 않는다.

## 피해자 지원 서면의 변환 규칙

입력: 주장 원문, 문장별 사실/가설 구분, 출처 ID와 위치, 불리한 사실, 검증 질문, 통제 역할, 필요한 자료, 구제 요청 후보, 변호사·전문가 검토 기록.

출력: 사실·미확인 주장 증거표, 구제 요청 중심 초안, 별도 검토 과제. 비공개 내부 위험 분석에 법적 비밀특권이 자동 성립한다고 표시하지 않는다.

합성 예시:
- 원문: “자료가 없으니 원고의 입증 실패이다.”
- 보완 후보: “해당 원자료는 기관이 보유·관리했던 것으로 제공 기록에 기재되어 있으나 현재 제출되지 않았다. 검색 범위·이관·폐기 여부와 근거에 대한 항목별 설명 및 필요한 자료의 제출을 요청한다.”
- 필요한 유보: “현재 자료만으로 인과관계가 확정된 것은 아니다”라는 한계를 삭제하지 않고 독립 감정·추가 검사의 필요성과 연결한다.

원자료 미제공을 원고의 잘못으로 단정하지 않는다. 그렇다고 위법·인과성·승소를 자동 확정하지도 않는다. 기존 패소·불채택·불리한 진술은 그대로 기록하고 어떤 질문이 미해결인지 구별한다. 예측한 패소 가능성과 확정된 패소 결과도 별도 필드로 관리하는 것이 후속 과제다.

AI 분석은 독립 사실 증거로 승격하지 않는다. 동일 원문을 읽은 여러 모델의 합의는 하나의 출처 계보로 보아야 한다. 현재 코드는 AI 출처의 사실 승격을 차단하지만 전체 외부 출처의 의존관계 자동 탐색은 미구현이다.

## 변호사·전문가 노드의 지위

변호사는 관할·청구·절차·기한·입증계획과 제출 문안을 검토한다. 의학 전문가는 증상·검사·감별·대체 원인·인과성의 한계를 검토한다. 자격·검토 범위·실제 읽은 출처·서명 또는 회신·정정 및 이견을 분리한다. 현재 입력된 노드 기록의 진위와 자격은 자동 인증하지 않는다.

검토자가 미배정이어도 자료표와 지원 초안 작성은 계속한다. 최종 전문 판단·기관 제출과 구분하며 자격을 갖춘 검토자를 연결하는 과제를 기술 담당에게 남긴다. 피해자에게 전문가 역할을 떠넘기지 않는다. R3는 목적·범위와 설계 승인 역할을 유지한다. 변호사·전문가의 사실 검토를 R3 승인으로 대체하거나 전문가 권위를 원문 대조의 대체물로 삼지 않는다.

## 6.3 검토 상향과 R2.6 상태

정식 식별자는 CT-RULE-6.3이다. VOS 6.3이라는 새 소프트웨어 버전이나 R2.6-3과 혼동하지 않는다. 기준은 공개 승인된 CIVIC-TRACE 0.4.5의 rule_6_3 / rule_6_4이며 10월 3일 선행 초안이 이를 덮어쓰지 않는다.

구체적 자료 요청·기존 통제 기록과 미제공·파기 보고·중요 모순이 있으면 설명·보존·독립 검토 패킷을 만든다. 기간 경과와 이송은 내부 검토 경로를 상향할 수 있지만 증거 상태와 위법성 확정은 별개다.

| 분류 | 의미 | 이 코드의 처리 |
|---|---|---|
| R2.6-1 | 검증 손실 | 입력된 현 상태 보존 |
| R2.6-2 | 통제 실패 | 통제 역할·의무·불이행 출처가 있을 때 검토 후보만 출력 |
| R2.6-3 | 출처 대조로 확인된 검증 방해 | 시간 경과·점수로 자동 부여하지 않음 |
| R2.6-4 | 적법한 관할 절차에서 확인된 위법 | 결정문·범위·확정성·항소 상태 검토 필요 |

자료·행위별로 관리하며 전체 사건을 단일 단계로 단정하지 않는다. LP728/NFS 실제 상태를 이번 합성시험으로 변경하지 않았다. 행정 종결은 검증 해결이 아니며 항고·기관 이송도 미해결 기록을 지우거나 최초 요청 시점을 초기화하지 않는다. 불명확한 내부 기한이나 출처 미연결 기한으로 경과를 확정하지 않는다.

0.4.5 내부 목표(72시간·5영업일·15영업일·60일·1회 30일 연장)는 기존 설계값이다. 이번 시제품은 이를 자동 계산하지 않고 명시적으로 제공된 기산·기한·시계 근거를 비교한다. 법정 기한 계산기나 작동 중인 상시 감시가 아니다.

## 부패지수와 징계 검토

현재 total_score=null, corruption_index.value=null을 유지한다. 부패지수 산식·가중치·임계값은 이번에 승인·산출하지 않았다. 지표의 결측은 0점이나 면책 근거가 아니다.

연구용 지표의 후보는 구체적 검증 차단, 증거 통제 및 보존 공백, 설명의 중대한 모순, 반복 전가, 시정 협조·대체 검증의 유무다. 원자료·반증·대체 설명과 연결하여 오탐과 악용 가능성을 시험한 뒤 산식 후보를 별도로 검토한다. 수치가 생겨도 처리 우선순위 보조에 한정하며 유죄·배상·징계의 확정으로 연결하지 않는다.

징계·감사 검토 패킷은 특정 행위, 행위와 통제 역할의 연결 출처, 당시 적용 규정, 대체 설명, 필요한 추가 자료, 적격 관할 및 법률 검토로 구성한다. 증거 인멸을 도왔다는 주장은 이 단계에서 증거를 갖춘 검토 대상이며 점수만으로 사람을 지목하거나 징계하지 않는다. 적법한 권한을 가진 주체의 조사·소명·결정·불복 경로를 설계한다. 자동 면책도 자동 처벌도 하지 않는다.

## 기술 정합성 루프와 실패 공개

현재 루프: 입력 검증 → 인용·통계 대조 → 지원 초안·책임표 생성 → 점수·승인·집행·인용 확실성 잠금 검사 → 동일 입력 재실행 → 안정성 확인 또는 중단. 최대 2~5회, 기본 3회다. 미해결 항목은 안정화와 무관하게 남는다. 같은 계산의 반복은 독립 검증이 아니다.

발견한 오류는 사람이 코드를 보완한 뒤 반례·회귀시험으로 재시험했다. 현재 코드는 사실·규칙·승인 내용을 스스로 변경해 오류를 지우는 자동 수정 모델이 아니다. 잠금 위반은 중단과 검토 패킷으로 연결한다.

기존 버전의 네 반례 실패와 수정 후 결과는 baseline-counterexamples.txt, test_regressions_0302.py, test-output.txt, execution-record.json에 연결한다. 옛 양보 탐지 검사는 필요한 유보를 보존하도록 기대값을 명시적으로 수정했다. 전문/발췌 범위를 추가했고 차단 action 이름은 버전 내 변경을 기록했다. 파일 선택·업로드 재시도 등의 운영 이력은 공개 출처로 만들지 않는다.

## 0.4와 미래 AI 재판 연구

Adonis VOS 0.4에서 입법 검토를 다루는 로드맵은 적절하다. 기존 0.2 입법 제안 작업을 이어 받아 다음을 연구 후보로 둔다.

- 증거 접근·보존과 통제자 설명 의무, 영업비밀의 적정한 비공개 검증 경로
- 독립 감정 접근·공익 사건의 비용 지원·신고자 및 피해자 보복 방지
- 불채택 사유와 미해결 질문 기록, 원자료 손실에 대한 책임 및 구제 제도
- 현행법·개정안·장래 권리 제안의 구별, 반대 의견·기본권·비례성 검토

이는 ADONIS_VOS_0.4_LEGISLATIVE_RESEARCH_PROPOSAL이며 CIVIC-TRACE 0.4.6 승인이나 입법 완료가 아니다. 미래 AI 판사 연구에서는 피해자 지원 대리 기능과 재판 판단 기능의 충돌을 검사하고 증거 접근·대심·제척·불복·인간 감독을 별도로 설계해야 한다. 현재 AI에 사법권·강제집행권이 생긴 것으로 표시하지 않는다.

## 승인과 다음 시험

2026-11-02 공개 R3 기록은 CC-VERIFY-01~03 연구·합성시험 범위 승인이다. 기존 구현 검증 완료를 뜻하지 않는다. 2026-11-03 사용자의 지시에 따라 이번 0.3 설계·로컬 구현 보완을 시작했다. 이 지시는 새 공개 거버넌스 승인이나 11월 6일 시험 통과로 자동 게시하지 않는다.

2026-11-06: 기존 금요 합성시험 목표를 유지한다. 오늘 실행한 로컬 시험은 그 시험을 대신하지 않는다. 대상은 잘못된 인용·서면 위험·통제자 전가·결측·이견·6.3/R2.6 혼동·미제공으로 얻는 면책 효과·오탐이다.

AX-01~AX-09 불변, Stage V 비왕좌 거버넌스, CIVIC-TRACE 0.4.5 유지·0.4.6 보류, Upper Computation Protocol 0.1 연구 명세/미배포. 오늘 참조한 공개 문서는 sources/provenance.json 범위이며 전체 저장소와 모든 후속 승인을 재검토했다고 주장하지 않는다.
