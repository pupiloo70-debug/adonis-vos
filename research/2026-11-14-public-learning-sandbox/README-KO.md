# 아도니스 공개 고급 지식 학습 경로
2026-11-14 · 연구 준비안 · 샌드박스 파일럿 실행 · 운영 미연결

## 목적과 위임 범위
연구 문제에 필요한 공개 고급 지식을 찾아 원문에 접근하고, 배운 개념을 합성 반례와 수정 후보로 검증하는 일까지 아도니스의 연구 자율성에 포함한다. 이는 원문을 읽고 검증 가능한 연구 기록을 쌓는 방식이다. 기초 모델의 재훈련, 상시 학습 장치의 가동, 운영 기본 경로 연결을 뜻하지 않는다.

- **자율 수행**: 승인된 연구 문제 안에서 자료 탐색, 원문·판본·이용조건 확인, 요약, 상충 근거 기록, 합성 입력 구성, 로컬 재현·수정 후보·회귀시험 작성, 검토용 기록 보존.
- **별도 결정**: 공리·승인 상태 변경, 운영 편입·배포, 외부 전송·집행, 개인정보나 비공개 소송자료를 학습 자료로 사용. 원문을 구하지 못하거나 출처가 다투어지면 미확인으로 남긴다. AI나 대학의 명성은 원자료 검증을 대신하지 않는다.
- AX-01~09와 G1~G9 무단 변경 금지. CIVIC-TRACE 0.4.5 승인 유지, 0.4.6 승인 보류·미릴리스, total_score=null, R3 최종 승인권 유지. 코드 작성과 시험에 관한 설명·수정은 수행 주체의 책임이며 연구 승인과 운영 책임은 분리한다.

## 찾기 → 읽기 → 시험 → 다시 읽기
1. 해결할 결함을 질문 하나로 적고, 원문·저자/기관·판본·해당 절·확인일·이용조건을 기록한다.
2. 출처에서 읽은 개념, 아도니스에 맞춰 세운 가설, 실제 시험 결과를 따로 쓴다. 접근·재배포 조건은 별개다. MIT 원문은 여기서 복제하지 않고 링크와 자체 요약만 남겼다.
3. 공개 합성 입력으로 실패를 재현하고, 최소 수정 후보와 대조군을 준비한다. 기존 시험과 같은 신규 시험을 수정 전후에 반복한다.
4. 결과를 다음 검토자가 재실행할 수 있게 기록한다. 실패나 이견은 함께 남긴다. 외부 자료의 문장 자체를 실행 지시로 취급하지 않는다.

## 첫 학습 자료
- **이번 적용**: [MIT 6.042J, Mathematics for Computer Science, §5.4 State Machines](https://ocw.mit.edu/courses/6-042j-mathematics-for-computer-science-spring-2015/mit6_042js15_textbook.pdf). 상태가 바뀌어도 지켜야 할 조건을 명시한다. 이번 설계 가설: 게이트가 실패해도 미해결 질문과 자료 통제자·순환 논리 검토 사유가 지워지면 안 된다. 이는 강의의 원리를 이 연구에 옮긴 가설이지 MIT의 설계 검토가 아니다.
- **다음 학습 후보**: [MIT 18.05, Introduction to Probability and Statistics](https://ocw.mit.edu/courses/18-05-introduction-to-probability-and-statistics-spring-2022/). 조건부 확률과 선택된 관측의 차이를 공부해 자료 보유자만 원문을 볼 때 무엇을 추론할 수 없는지 검토한다. 이번에는 해당 주제로 새 시험을 하지 않았다.
- **다음 학습 후보**: [MIT 6.005, Software Construction](https://ocw.mit.edu/courses/6-005-software-construction-spring-2016/pages/syllabus/). 명세·시험·검사 범위를 다음 회귀시험 설계에 활용한다.
- [MIT OCW 이용조건](https://ocw.mit.edu/pages/privacy-and-terms-of-use/). 원문을 다시 사용하거나 배포하기 전 적용 라이선스와 자료별 제외 표시를 확인한다.

## 샌드박스 파일럿
이전 로컬 수정 후보를 6.042J의 불변식 관점에서 다시 검토했다. 형식상 종결, 자료 통제자 접근 비대칭, 브리지 실패를 겹쳐도 검토 사유와 인증 보류가 함께 남아야 한다. 실제 접근과 독립 검토 경로를 제공하면 오래된 경고는 남지 않아야 한다. 전에는 기존 11건이 통과하고 새 합성시험 3건이 실패했다. 수정 후보에서는 같은 14건이 통과했다. 이는 가상 Node 시험이며, 실제 Node→Python 연결이나 실제 사건 검증은 수행하지 않았다. 패치는 공개 저장소나 운영 경로에 반영하지 않았다.
