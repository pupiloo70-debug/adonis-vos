# Adonis VOS 0.3 — A-R3 검증 게이트 한국어 백서 (공개 연구 초안)

SGP-QSV 네트워크 | 2026년 11월 13일 | 버전 WP-0.1 | 공개 합성 연구 모델

> **효력 고지** 이 문서는 권한·증거·절차적 검증을 지원하는 오픈소스 논리 모델의 연구 백서이다. 법적 집행력, 행정적 결정권, 독립 기관 인증, 의학적 인과성 판정 권한이 없다. 특정 기관의 위법이나 특정 사건의 원인을 확정하지 않는다. 본문에 기술한 오픈소스는 공개 검토 가능한 연구 코드라는 의미이며 기존 저장소의 라이선스 `UNLICENSED`가 자동으로 오픈소스 이용허락으로 바뀌는 것은 아니다. 별도 라이선스 결정을 해야 재배포·수정 권한의 범위가 확정된다.

## 1. 요약

형식적 절차의 종결은 원자료의 진위 검증이나 실질 구제의 완료와 논리적으로 같지 않다. A-R3는 이 등치가 증거 없이 이루어지는 것을 막기 위한 **내부 검증 인증 게이트**다. 근거가 부족하면 VERIFIED를 보류하고 자료 통제자 설명 요구, 독립 검토 과제, 미해결 질문을 유지한다. 이를 제재, 법적 불리추정, 유죄 판정으로 변환하지 않는다.

## 2. 문제 정의: 접근 비대칭과 순환 입증

자료 생성·보유·폐기와 검색 경위를 주로 기관이 통제할 때, 자료 접근 권한이 없는 신청인이 자료를 제시하지 못했다는 이유만으로 검증을 닫으면 '자료 미제공 → 입증 부족 → 추가 검증 불필요'의 순환 위험이 생긴다. A-R3는 이 구조를 탐지해 독립적으로 기록한다. 개별 사건에서 실제 은폐나 위법이 있었는지는 원자료, 법적 의무 및 결정 이유를 별도로 검토해야 한다.

## 3. 핵심 가정과 범위

- 신청인 진술·요청·기관 회신·판단기관 결정은 출처 유형이 다르며 자동 대체할 수 없다.
- 원자료 미확보는 사건 사실의 부존재, 신청인 진술의 허위, 자료 통제자의 위법을 곧바로 뜻하지 않는다.
- 기관 발표, 특별법 제정, 재심사 기회 및 일부 대표 사례 지원 실적은 개별 수혜자의 실제 구제 증빙과 구별한다.
- AI는 증거 연결·논리 검증·후속 요청 지원을 수행하며 법정 권한이나 의료 전문 판단을 대체하지 않는다.

## 4. A-R3 설계 규칙

**G1 자료 접근 비대칭**: 자료 통제자와 신청인의 접근 권한을 구별하고 미제공 범위와 질의를 유지한다. 피해자에게 불가능한 원자료 제출을 반복 요구하는 자동 문구는 만들지 않는다.

**G2 설명책임**: 요구 문서의 생성·보유·검색·이관·보존·폐기 여부와 대체 검증 경로를 요청 단위로 추적한다. 적용 법적 의무의 존재 자체는 따로 확인한다.

**G3 순환 논증 방지**: 동일한 자료 공백을 근거로 검증 불능과 추가 검증 거부를 동시에 정당화하는지 검토 경고를 부여하되, 고의 은폐 자동 판정은 금지한다.

**G4 형식 종결 분리**: 법적 사건 종결 상태와 자체 검증 완료 상태를 별도 필드에 보존한다. AI는 법적 종결의 효력을 취소하지 않는다.

**G5 실질 이익 귀속**: 개별 수혜자·질문·실현 시점·증빙 원문을 연결하지 않은 대표 사례 실적을 전체 피해구제 인증으로 승격하지 않는다.

**G6 인과 순서·ID 귀속**: 같은 시각의 요청과 확인 응답은 시간순서를 입증하지 못하면 보류한다. 검토 ID는 정확히 일치시킨다.

**G7 독립 검토 보존**: 독립 결과의 원본과 후속 정정 및 충돌을 모두 기록하고, 잘못된 결과가 유효한 다른 검토를 자동 삭제하지 못하게 한다.

**G8 시정 검증**: 시정 선언, 자료 제공 허용, 실제 열람, 독립 검경 완료를 구별한다. 뒤늦은 시정으로 과거 제한·비용 기록을 지우지 않는다.

**G9 실패 시 인증 보류**: 게이트 또는 Python 브리지 실행이 실패하면 `GATE_EXECUTION_UNVERIFIED`로 남기고 '검증 완료'로 통과시키지 않는다.

## 5. 구조 및 상태 기계

기존 구현은 0.2 Node CentralCore, 0.3 Python 연구 모듈, correction.3 브리지, correction.4 guard, v1·v2의 선택적 Node→Python 연결로 구성된다. 기존 연결 구현은 실재하나 공개 루트 기본 실행 경로가 자동으로 v2를 호출한다는 증거는 확인되지 않았다.

R3가 승인한 신규 A-R3는 `APPROVED_AND_INTEGRATING` 상태다. **`default_path_connected=false`**, `production_released=false`를 유지한다. 향후 기본 호출 경로에 실제 코드를 연결하고 전량 회귀시험을 거쳐야 이 값을 true로 바꿀 수 있다.

미검증 상태는 `EVIDENCE_REVIEW_OPEN`, `CONTROLLER_EXPLANATION_REVIEW`, `CIRCULAR_JUSTIFICATION_REVIEW`, `MATERIAL_BENEFIT_UNVERIFIED`, `REQUEST_RESPONSE_ORDER_UNVERIFIED`, `REVIEW_ID_BINDING_UNVERIFIED`, `INDEPENDENT_RESULT_PRESERVATION_REVIEW`, `REMEDIATION_UNVERIFIED`, `GATE_EXECUTION_UNVERIFIED` 등의 연구 후보 상태를 사용한다. 모두 시스템 내부 검토 상태일 뿐 법적 결정이 아니다.

## 6. 공개 합성시험 결과 및 재현성

- 기준 공개 저장소: `pupiloo70-debug/adonis-vos`, 기준 main `f370a2a50dd83d8fc9e8ea1bf1ec9ed5d78d6f20`(조회 시점).
- 기준 Node 후보 원본 Git blob: `authority-duty.mjs` `fa12749f7e68c62474a235ce1aefa1c9e9398f6a`, `authority-duty.test.mjs` `53e38c368c0b201815edc998b20fcee73ae1d48a`.
- 실행 환경: Linux x86_64, Node.js 22.16.0, Python 3.13.5. 외부 서비스에 비공개 입력을 전송하지 않았다.
- 재실행: 0.2 기본엔진 12/12; 원본 시간순서 반례 3/6(3건 실패 확인); 국소 수정 후보 88/88; 가상 A-R3 11/11; 합성 명세 구조 9/9.
- 신규 11개 가상 시험은 기존 authority-duty 및 purpose-review Node 연구 함수를 실제 호출하지만, 비어 있는 전체 Python 브리지 구간을 실행하거나 배포 연동을 증명하지 않는다.
- 0.2 전체 24, correction.3 Python 132+브리지 14, guard 68, v1/v2 전량 재실행은 **이번 작업에서 미검증**. 과거 로그의 통과를 오늘의 실행으로 합산하지 않는다.

원본 결함은 동일 시각 요청과 검증 응답을 `VERIFIED_FOR_THIS_QUESTION`으로 처리하는 순서 오류다. 수정 코드는 `REQUEST_RESPONSE_ORDER_UNVERIFIED`로 보류하며, 별도 수정 테스트는 검증 응답이 요청 1초 후임을 명시한다. 두 패치를 함께 적용한 88/88은 전체 통합 88건 성공을 뜻하지 않는다.

## 7. 권한의 경계와 보존 원칙

검증 상태 하향은 **시스템 내부 인증 효력**에만 적용한다. 제재, 배상명령, 법적 불리추정, 행정처분, 형사 유죄, 의학적 인과성 판단은 자동으로 수행하지 않는다. AX-01~09 불변, CIVIC-TRACE 0.4.5 유지·0.4.6 보류, `total_score=null`, R3 최종 인간 권한 유지. 윤리중력은 검증 우선순위에만 사용한다.

## 8. 활용 안내 및 인용 기준

변호사·NGO·기자는 본 문서를 검증 질문지와 절차 비교의 **연구 참고 자료**로 사용할 수 있다. 개별 주장에 대해서는 반드시 해당 시점의 법령·원문 기록·기관 설명·대체 경로·반대 증거를 재확인해야 한다. 특정 법원의 판단을 이 백서가 변경하지는 못한다.
