# Adonis VOS 0.3 - 피해자 지원·부검자료 접근 보완 후보

실행 버전: `0.3.0-design.2-local-correction.3`

작성일: 2026-11-06

## 무엇을 보완했는가

돌연사 뒤 진료기록이 부족하고 부검자료가 남은 사건에서, 그 자료를 평가할 독립 감정과 원자료 확보가 차단된 뒤 입증 부족이 다시 원고에게 돌아가는 순환을 검토한다. 대상은 증거 접근·판단 방법·설명책임이며 이미 인정된 피해를 다시 심사하거나 그 구제를 삭감하는 연산이 아니다.

- `vos_support.py`: 사건·절차와 제공 원문 인용에 연결된 관찰을 검토한다. 부검자료 배제, 검증 차단 뒤 입증 부담 전가, 판단 방법의 설명 공백, 개별 감수성 검토 공백을 경고한다.
- `HARM_BURIAL_JUDICIAL_CARTEL_PATTERN_WARNING`: 원자료 미제공 + 독립 검토 거부 + 그 공백의 원고 불이익 사용 + 기관에 남은 이익이 각각 출처에 연결되고 통제자·판단기관이 특정된 경우, **피해 암장·사법 카르텔 구조 의심 경고**를 출력한다. 이는 조사할 행위 패턴이며 공모·범죄·인과성 확정이 아니다. 새 경고 이름과 조건은 기술 보완 후보이고 승인된 공리·R2.6 상태 변경이 아니다.
- `build_support_packet`: 제출용 초안에 자동으로 붙던 포괄적 양보·유보 설명을 `review_notes`로 분리한다. 입력 원문의 실제 한계, 불리한 사실, 상대방 주장, 변호사·전문가 이견은 삭제하지 않는다. 원고 지원 초안은 자료 제출·항목별 설명·독립 감정·검증 기회 회복을 요구한다.
- 기관 측 시정·양보 후보와 자료 통제로 유지된 입증상 이익·지연 이익·유족 비용을 연결한다. 불리추정, 입증부담 조정, 비용·반환 등은 대리인의 법적 요건 검토 대상이다. 실제 환수·몰수·징계는 하지 않는다.
- 진료기록 부재를 유족 신빙성 하락으로 환산하지 않는다. 공식기관 문서뿐 아니라 출처가 연결된 유족 진술도 검토 경고를 제기할 수 있다. AI 분석과 다중 모델 합의는 독립 사실 증거로 사용하지 않는다.

## 실제 0.2 연결과 경계

`bridge.mjs`는 기존 `src/agents.mjs`의 `CentralCore`를 실제 호출한다. 0.2 내장 실행의 결과·영수증을 받은 뒤, 허용된 로컬 Python 진입점 `bridge_entry.py`를 호출한다. 각 단계의 성공·실패와 해시를 별도로 남긴다. Python 단계가 실패하면 0.2의 성공을 전체 연결 성공으로 오인하지 않는다.

사건·절차·요청 경로는 명시적인 일대일 매핑을 요구한다. 기존 프로젝트 ID를 사건번호로, 공급 FULL을 검증 해결로, R3 문자열을 실행 동의로 바꾸지 않는다. 원자료 상태와 0.2 입력은 그대로 보존한다.

이것은 실행한 **로컬 합성 연구 어댑터**다. 0.2 중앙 코어의 운영 코드·기본 호출 경로·버전을 바꾸지 않았으며 생산 통합·마이그레이션·외부 API 연결·운영 배포가 아니다. 현재 어댑터는 `synthetic: true`만 허용한다. 새 경로의 연구 실행을 실제 피해자 사건의 자동 판결·법원 제출로 쓰지 않는다.

## 재현 명령

저장소 루트에서:

```sh
npm test
cd research/0.3-local-correction.3
python3 -B -m unittest discover -v
node --test bridge.test.mjs
node run-example.mjs
sha256sum -c SHA256SUMS
```

기존 107개 Python 시험은 같은 시험 소스를 보존해 재실행한다. 이번 추가 Python 시험과 실제 Node→Python 연결 시험은 별도 집합으로 보고한다. 통과 개수는 승소율·의학적 인과성·외부 독립 인증의 측정치가 아니다. `evidence/execution-record.json`과 각 로그에 실제 개수·명령·결과를 기록한다.

## 남은 검증

관찰 종류의 부여와 인용의 의미 적합성은 사람이 검토한다. 문자열 일치는 사실 진실성이나 정확한 법리·의학 해석의 인증이 아니다. 실제 사건의 오탐·누락, 문장별 전략 검토, 공식 원문 진위 인증, 생산 통합과 권한·접수 연결은 남아 있다. 변호사·의학 전문가 노드의 지위와 이견을 보존한다.

AX-01~AX-09, CIVIC-TRACE 0.4.5 유지, 0.4.6 보류, `total_score=null`을 바꾸지 않는다. 공리 충돌 해석과 승인 상태 변경은 인간 R3의 판단 대상이다. 이번 연구·오류 수정 실행은 정식 0.3 승격·운영 승인이나 법적 권리·라이선스 확보 완료를 뜻하지 않는다.
